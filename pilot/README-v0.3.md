# 临考 v0.3 首轮试用指南

本指南适用于 **v0.3-alpha.1** 的题单与工作台。旧版 [v0.2 试用包](README.md) 和 `output/pilot-runs/batch-01/` 保持原样；新版使用独立批次 **`output/pilot-runs/v0.3/batch-01/`**。不能把旧批次的学习记录当成新版试用数据，也不要为了验证迁移而修改旧库。

本轮先邀请 3–5 位正在学习或近期学过高数的学生，一次一位，在主持人电脑上体验。目标是观察能否找到合适的题、完成作答、理解反馈和复习安排；不据此推断考试提分或整体学习效果。固定版本和提交号后再开始，不在同一批中途换题或修改判题。

## 独立启动

先按 [应用说明](../app/README.md) 准备依赖并运行测试，结果以 [QA.md](../app/QA.md) 为准。新版演练也使用本节的新数据库，**不要运行旧版的 `pilot/start-trial.bat`**，其路径仍属于 v0.2 批次。

在仓库根目录的 PowerShell 中运行：

```powershell
$env:LINGKAO_DB_PATH = Join-Path (Get-Location).Path 'output\pilot-runs\v0.3\batch-01\learning.sqlite3'
.\app\start.bat --port 8010
```

这里先形成绝对数据库路径，避免启动脚本切换到 `app/` 后写到其他位置。服务会自动创建所需目录。保留终端，用专用浏览器配置打开 [8010 本机页面](http://127.0.0.1:8010/)。打开 [健康检查](http://127.0.0.1:8010/api/health) 核对 `version` 为 `0.3-alpha.1`；`ai_enabled` 只表示是否配置密钥，不证明远端连通。

**必须为这个批次使用独立浏览器配置。** 同一配置中的 Cookie 不按端口隔离，只把 8000 改成 8010 不会隔离身份；多个无痕窗口也可能共用 Cookie。不要同时打开开发库、旧批次和新版批次的学习页面。

结束试用后关闭服务。这个 PowerShell 的数据库环境变量仍然存在；另开终端进行日常开发，或明确移除该环境变量后再启动默认库。恢复本批时重新执行同一命令，并使用原专用浏览器配置。

## 演练与 AI 模式

准备纸笔、观察表和计时工具，用演练身份走通“选预算 → 选题 → 提交 → 复习 → 新题检查 → 记录导出”。主持人自行查看的题目不能计为学生首次接触题目。结束演练先导出需要保留的记录，再清除／更换测试者，核对新身份不含演练答案。

本次交付未配置有效 DeepSeek 密钥，真实请求尚未验收。默认以离线讲解模式开始。若组织者要开展在线答疑试用，应先按 [AI 配置说明](../app/README.md#deepseek-自由答疑) 在本机填写密钥，不需要在聊天中提交密钥；先单独演练四类题的真实问答并记录日期、模型和结果。未完成这一步时，不把模拟服务测试描述为真实 AI 可用性验收。

在线模式会把当前题、审核解法、相关知识、当前题最近提交和最近六条对话发送给 DeepSeek；开始前用这句话向参与者说明。是否使用 AI 由学生决定，不要求为了检查功能而先看答案。整批记录相同配置和模式；若中途切换，按不同条件记录，不能混为一组效果数据。

## 每位学生的流程

1. 用 P01、P02 等匿名编号记录学习背景大类、是否见过本版题目；阅读本指南的学生说明并确认愿意参加，不收集姓名、学号或联系方式。
2. 让学生选择真实的 15–240 分钟预算；当面试用可预留 30–45 分钟。说明页面预算是预计任务量，不是倒计时；观察表另记实际时间。
3. 由学生决定先做四题诊断，还是直接浏览题单。观察是否理解推荐理由、资料来源、筛选和“自由选择”。未做诊断不补记为会做或不会做。
4. 学生纸笔推导并在网页提交最终表达式。观察输入、切题后草稿、提示、题解及答疑是否能解决问题。主持人只提供必要操作帮助；口头数学帮助须记录，不能被总结为独立完成。
5. 学生可在待复习中重做原题，或条件满足时做该题型两道即时复测。次日检查要在首次完成即时复测后至少 24 小时，不修改时钟或数据库提前开放；同日体验未发生延迟复测，明确记录“尚未到期”。
6. 在学习记录中请学生自行解释“首次独立、辅助、重试、待核对”及下一步打算，再访谈。记录其原话后再澄清，避免先解释影响观察。

当前内容为通用原创积分训练，不声称来自学生本校。可以询问“如果有本校真题和作业，你希望题单如何变化”，但不要将假设当成已实现的功能。

学生说明可直接读给参与者：

> 临考会按你的时间和作答记录安排练习，你也可以自由选题。先在纸上推导，再输入最终表达式；这里不批改过程分。不会做时可以使用帮助，系统会分别记录独立、辅助和重试结果。诊断与新题检查没有中途提示，可以提前结束。你可以随时停止，不需要为了体验把题做对；我们主要想知道哪里不好用或讲不清楚。

可复用 [观察表](observation-template.csv)、[反馈问题](feedback.md) 和 [汇总模板](summary-template.md) 的空白结构，填写副本放在新版批次目录。环节记录改用“题单／工作台／待复习／新题检查／学习记录／AI等待”；未发生的旧固定流程环节留空，不强制学生按旧顺序走完。

## 导出与交接

非测评阶段导出学习记录，存为 `output/pilot-runs/v0.3/batch-01/P01/P01-learning.json`。核对 JSON 可读取，`app_version` 为 `0.3-alpha.1`、`export_format_version` 为 3，匿名身份、逐次作答、辅助及事件与观察大致一致；未提交草稿不会进入导出。

先确认文件已保存，再清除／更换测试者。重做原题不会重置身份或擦除既有证据，不能代替换人。新学生不应看到上一个学生的答案与聊天。

学生在测评中停止时，允许其自行明确结束本轮后导出；已呈现题保留已见，不能重新按未见题评价。不要求为了导出替他作答或代点跳过。如果保留中断状态等待继续，就记录暂未导出，并给下一位使用另一专用浏览器配置。AI 正在等待时，先取消或等待结束，再清除身份。

需要次日继续时保留该学生身份并使用原浏览器配置；若同台电脑要给其他学生体验，为每人保留各自配置。给次日未回访、未到期或主动停止分别记录原因，不伪造完成数据。

```text
output/pilot-runs/v0.3/batch-01/
  batch-summary.md
  learning.sqlite3
  P01/
    observation.csv
    feedback.md
    P01-learning.json
```

真实资料只保存在被 Git 忽略的 `output/`。本指南和 `pilot/` 模板保持公开空白。备份时先停服务，保存数据库及存在的 SQLite 辅助文件；整库含会话信息，不作为公开附件。参与者要求不保留资料时，处理对应记录、导出和备份中的资料。

## 本轮重点与停止条件

优先核对：能否解释为什么推荐这道题、能否自由换题且找回草稿、最终表达式能否顺利输入、是否理解来源均为原创、AI等待是否可取消、是否区分重做原题与未见题检查，以及是否正确理解学习记录。

发现记录丢失、不同学生记录混入、可复现数学误判或保留答案泄露时暂停试用，保留最小复现证据后修复。核心操作卡住记录为优先问题；能继续的文字与布局问题单独归类。“待核对”不等于已证明判错。

汇总使用原始人数、实际用时、介入次数、中断原因和学生原话。诊断与复测题未做等值难度标定，不能用其差值计算提分；未发生的 24 小时检查和未验收的真实 AI 请求必须明确注明。
