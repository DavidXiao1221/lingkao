## 问题清单

| 问题编号／级别 | 观察事实（动作、提示、次数） | 原话与证据位置 | 影响人数／经历该环节人数 | 我们的解释（待验证） | 是否可复现／复现步骤 | 临时处理 | 建议修复与验收条件 |
|---|---|---|---|---|---|---|---|
| | | | | | | | |

- **P0：** 已核实记录丢失、串入他人记录、数学误判或异常答案泄露。暂停后续试用，修复并回归后再开批次。
- **P1：** 无法完成核心操作或关键理解错误，需要主持人介入；优先修复。
- **P2：** 可继续但阅读、操作或讲解安排有改进空间；结合频次与影响排序。
- **待核对：** 当前证据不足，不伪装成已确认的缺陷。明确显示“待核对”的答案不自动列为 P0。

合并重复问题时保留每个人的证据，不按点击次数当作多个人。先写事实，再写解释；例如推测“没有看到按钮”必须与实际动作或原话对应。正向观察也可记录，但一次顺利操作不证明所有人都会顺利。
