# 临考试用说明

谢谢你来体验。今天使用的是 **v0.2-alpha.3**，内容只有一个换元积分单元。我们想了解页面、输入和讲解哪里需要改进；这不是考试，不要求你全部做对，也不需要提前复习。

## 今天会做什么

按页面依次完成：**起点诊断 → 阅读示范 → 引导练习 → 独立变式 → 新题复测 → 查看报告**。需要时可以进入基础补练，再回到原来的位置。全程加反馈预留约 30–45 分钟；实际用时如实记录，不催你赶进度。页面填写的学习时间只是预算，不是倒计时。

## 如何体验

- 可以在纸上写推导，再在页面输入最终表达式。页面有数学输入按钮和“输入方法与示例”。公式预览只帮助检查输入形式，不表示答案正确。
- 训练中按需要使用提示、示范、完整讲解和预设答疑，也可以跳过；这些选择都会被记录，没有要求你必须用或不能用。
- 诊断和复测期间没有提示或中途对错。不会可以按页面提示跳过；确认跳过后，本轮不能返回该题。
- 如遇操作不明白、输入不进去、提示看不懂，直接说出来。可以说出你的想法，也可以安静做题；不必边推导边解释。
- 看到“待核对”时，表示程序暂时不能可靠确认，不等于已经判错。请告诉主持人。

## 你需要知道的

本版只核对最终表达式，不评价纸笔推导；答疑是预先写好的讲解，**没有在线 AI，也不需要注册账号**。报告只描述本次题目的作答与帮助记录，不代表整门高数水平，不预测考试成绩。

试用在主持人的电脑上进行。我们用匿名编号记录操作现象、表达式、用时和反馈，不要求填写姓名、学号或联系方式，默认不录音录像。请不要在答案区填写个人信息。

**你可以随时暂停或停止，也可以提出不保留本次资料。** 结束后请告诉我们哪里顺畅、哪里困难，以及你希望接下来练什么；不会使用和不喜欢的地方都可以直接说。
