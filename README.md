# 临考 · Lingkao

面向考前突击场景的学习助手，从诊断、引导练习到独立复测，记录具体的学习证据。

当前版本：**v0.2-alpha.1**。首个单元为高等数学「换元积分」，可在本机完成完整学习流程。这是早期验证版本，尚未在真实学生群体中验证学习效果。

## 当前功能

```text
1 道诊断 → 1 个示范 → 2 道引导练习 → 2 道独立变式 → 2 道新题复测 → 学习报告
                     ↳ 1 道可选基础补练，完成后回到原位置
```

- 数学输入工具栏与公式预览，支持括号、分数、幂、常用函数和积分常数。
- 最终表达式等价性核对；格式错误不计为有效作答，漏写 `+C` 会保留为答案不完整的首次记录。
- 分层提示、示范、完整讲解与预设答疑，分别记录使用情况。
- SQLite 保存训练位置和逐次作答，刷新页面、退出训练或重启服务后可以继续。
- 诊断、复测期间隔离教学资料和中途判定；完成复测后统一展示结果。
- 报告区分首次独立完整完成、辅助完成、错误后重试、跳过和待核对，并支持导出学习记录。

**当前答疑使用预设讲解，不调用在线 AI。** 环境中已有 API 密钥也不会自动启用模型。首次安装依赖需要联网，安装完成后的学习流程可离线运行。

## 快速开始

需要 **Python 3.10 或更新版本**及现代浏览器。服务只监听本机 `127.0.0.1`。

### Windows

下载源码后，双击 [`app/start.bat`](app/start.bat)，然后打开 **http://127.0.0.1:8000**。使用期间保留终端窗口。

也可以在仓库根目录的 PowerShell 中运行：

```powershell
.\app\start.bat
```

### macOS / Linux

在仓库根目录运行：

```bash
bash app/start.sh
```

启动脚本会在 `app/.venv/` 中创建虚拟环境，并安装固定版本的 SymPy，不修改全局 Python。若端口被占用，可添加 `--port 8001`，并打开终端显示的地址。

学习记录保存在本机 `app/data/`，不随源码上传。继续学习时使用原浏览器配置文件与相同本机地址。详细操作、数据说明及开发接口见 [`app/README.md`](app/README.md) 和 [`app/CONTRACT.md`](app/CONTRACT.md)。

## 测试与验收

Windows：

```powershell
.\app\test.bat
```

macOS / Linux：

```bash
bash app/start.sh --test
```

本版本发布前在 Windows 本地执行 **70 项自动化测试，全部通过**，覆盖数学判题、学习证据、测评隔离、过期请求和 SQLite 持久化；另完成桌面及 390 像素宽度的浏览器流程检查。完整记录见 [`app/QA.md`](app/QA.md)。macOS / Linux 提供启动脚本，尚未实机验收。

## 项目结构与技术

```text
app/
├── web/             原生 HTML / CSS / JavaScript 页面
├── server.py        Python 本地 HTTP 服务、会话与 SQLite 持久化
├── engine.py        学习流程、题目实例与证据记录
├── grader.py        SymPy 数学解析、公式预览与判题
├── course.json      换元积分课程与题目
├── tests/           自动化回归测试
├── start.bat        Windows 启动入口
└── start.sh         macOS / Linux 启动入口
```

数学解析与判题在受限的独立 UTF-8 子进程中执行。浏览器使用不透明题目实例和状态版本提交操作，服务端校验过期或重复请求。

## 版本边界与后续方向

本版只核对最终数学表达式，不评价自由书写的推导过程；报告展示已发生的学习证据，不给出掌握百分比、提分承诺或通过概率。

后续方向包括真实 AI 答疑、更多积分单元、延迟复测、账号与跨设备同步。当前版本面向本机试用，尚未提供在线部署方案。

欢迎通过 Issues 反馈复现步骤、运行环境和预期行为。反馈时请勿附带个人学习数据库、会话凭证或密钥。
