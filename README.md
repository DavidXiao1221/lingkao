# 临考 · Lingkao

面向考前突击场景的积分练习助手：根据本次时间和作答记录安排练习，卡住时查看讲解，最后用未见题检查独立作答。

当前版本：**v0.3-alpha.1**。覆盖基本积分、换元积分、分部积分和定积分计算，提供题单、做题工作台、待复习和学习记录。当前内容均为临考原创的**通用积分训练**，尚未匹配具体学校或学期，也未验证真实学生的学习效果。

## 快速开始

需要 **Python 3.10 或更新版本**及现代浏览器。Windows 下载源码后，双击 [`app/start.bat`](app/start.bat)，打开 [本机学习页面](http://127.0.0.1:8000/)，使用期间保留终端窗口。

也可以在仓库根目录的 PowerShell 运行：

```powershell
.\app\start.bat
```

macOS / Linux 使用 `bash app/start.sh`。首次启动会在 `app/.venv/` 安装固定版本的 SymPy，不修改全局 Python。端口被占用时可加 `--port 8001`，并使用终端显示的地址。服务只监听本机 `127.0.0.1`。

**不配置 AI 也可以完整做题。** 安装好依赖后，题单、数学判题、预设讲解、复测和记录均可离线使用；DeepSeek 自由答疑需要单独配置并联网。详细操作见 [应用说明](app/README.md)。

## 这一版怎么练

1. 设置本次 **15–240 分钟**预算，选择四题快速诊断或直接进入题单。
2. 按推荐下一题练习，也可以按题型、难度和作答状态筛选，自由选题。
3. 在纸上推导，在工作台输入最终表达式；支持公式预览、分层提示、必要知识、示范、题解与 AI 追问。
4. 从待复习页重做原题，或在满足条件后做该题型的未见题复测。首次完成即时复测至少 24 小时后，开放一题次日检查。
5. 查看逐次作答、首次独立完成、辅助与重试证据；在非测评阶段导出学习记录。

课程共有 **32 道作答题＋4 个示范**：普通题单公开 16 道练习；另有 4 道诊断、8 道即时复测和 4 道次日检查。保留题只在相应测评中呈现，已见题不会重新获得“未见题”资格。

预算依据题目预计用时安排，预留复测及总结时间，不是倒计时。资料结构支持“真题 → 作业 → PPT → 教材”的依据优先级；这一版只使用原创资料和个人作答证据，不生成校内出题频率或“必考”判断。

## 配置 DeepSeek 答疑

在仓库根目录的 PowerShell 中执行一次：

```powershell
Copy-Item .\app\.env.example .\app\.env
```

然后在本机编辑器打开 `app/.env`，填写 `DEEPSEEK_API_KEY` 并重启服务。已有 `.env` 时直接编辑，不要覆盖。**密钥只在本机配置，不需要贴到聊天中。** `.env` 已被 Git 忽略；同名环境变量优先于文件值。

默认模型为 `deepseek-flash`，可通过 `DEEPSEEK_MODEL` 修改。默认每个匿名学习者累计 30 次、本机数据库每个 UTC 日 100 次、并发 2 次；具体参数见 [配置示例](app/.env.example)。请求等待期间可以继续编辑草稿，先等待完成或取消，再提交或换题。成功保存的 AI 回复计为辅助使用；失败不改变已有独立作答证据。

本次交付没有配置有效密钥，**真实 DeepSeek 调用尚未验收**；模拟服务验收与其他检查的结果见 [QA 记录](app/QA.md)。

## 数据、升级与试用

学习记录默认保存在 `app/data/lingkao-alpha.sqlite3`；未提交草稿保存在浏览器本地，草稿不属于作答记录。继续学习需使用原浏览器配置与原地址。重新练习只重置当前题的轮次，保留历史证据和其他题的草稿。

从 v0.2 升级前，先停止所有旧服务并备份数据库。新版自动迁移支持的旧状态，保留身份、原作答结果、判题版本、辅助和暴露记录；不重判旧答案。旧版未完成的诊断或复测用冻结课程继续，完成或明确结束后进入新版。详见 [迁移说明](app/README.md#从-v02-升级)。

**新版试用从 [v0.3 主持指南](pilot/README-v0.3.md) 开始**，使用独立数据库 `output/pilot-runs/v0.3/batch-01/learning.sqlite3` 和专用浏览器配置。原 [v0.2 试用包](pilot/README.md) 及 `output/pilot-runs/batch-01/` 作为旧批次保留，不用于新版演练或验证。

## 测试与技术

Windows 在仓库根目录运行 `.\app\test.bat`；macOS / Linux 使用 `bash app/start.sh --test`。测试使用临时数据库，不操作真实试用记录。检测到 Node.js 时同时运行前端草稿回归；日常运行只需 Python。测试结果和未验收项统一见 [QA.md](app/QA.md)，版本历史见 [CHANGELOG.md](CHANGELOG.md)。

```text
app/
├── web/             原生 HTML / CSS / JavaScript 页面
├── server.py        本机 HTTP、会话、SQLite 与异步请求
├── engine.py        题单推荐、轮次、测评和学习证据
├── ai_tutor.py      服务端 DeepSeek 适配
├── grader.py        受限表达式解析、公式预览与数学判题
├── course.json      四类积分题库和资料来源
├── legacy_engine.py 冻结的 v0.2 学习引擎
├── legacy_course.json 冻结的 v0.2 课程
├── tests/           内容、判题、状态、HTTP、AI 和草稿回归
└── start.bat        Windows 启动入口
```

数学判题在受限子进程中执行；AI 不参与判题或决定训练顺序。接口约定见 [CONTRACT.md](app/CONTRACT.md)。

本版只核对最终表达式，不批改纸笔推导过程，不预测分数或通过概率。暂不提供账号、跨设备同步、真实资料上传解析、排行榜、社区和在线部署。反馈问题时请提供复现步骤，不附带数据库、Cookie 或密钥。
