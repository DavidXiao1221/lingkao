# 临考 v0.3-alpha.1

本机运行的通用积分训练：**题单 → 做题工作台 → 待复习／未见题检查 → 学习记录**。覆盖基本积分、换元积分、分部积分和定积分计算。先在纸上推导，再提交最终表达式；系统不评分推导过程。

## 启动与测试

需要 Python 3.10 或更新版本。Windows 双击本目录的 `start.bat`，打开 [本机页面](http://127.0.0.1:8000/)，保留终端窗口。也可在本目录的 PowerShell 中运行：

```powershell
.\start.bat
.\start.bat --port 8001
.\test.bat
```

每次只启动一个所需服务。首次在本目录创建 `.venv` 并安装固定版本 SymPy，需要网络；依赖齐备后不会重新安装。macOS / Linux 可用 `bash start.sh`、`bash start.sh --port 8001`、`bash start.sh --test`；实机验收范围见 [QA.md](QA.md)。

测试脚本在 Python 测试通过后，用已安装的 Node.js 执行 `tests/test_drafts.cjs`。没有 Node.js 时会明确跳过前端回归；运行学习工具不需要 Node.js。直接开发启动可使用 `.venv\Scripts\python.exe server.py --port 8000`。

仅监听 `127.0.0.1`，其他设备不能访问。使用终端实际显示的地址；同一个匿名身份要继续使用原浏览器配置及原主机名。

## 学生操作

1. 选择本次 15–240 分钟预算，可先做四题诊断或直接刷题。未诊断题型保持未测试。
2. 在题单查看推荐理由、难度、预计用时、来源和个人状态；可按题型、难度、状态筛选，也可自由换题。
3. 工作台提供题目、必要知识、题解和来源；桌面双栏，窄屏用单栏与标签页。输入支持 `x^2`、`exp(x)`、`sin(x)`、`cos(x)`、`ln(x)`、`sqrt(x)`、`pi` 和 `+C`；乘号用 `*`。
4. 先独立尝试，再按需要打开提示、示范或答疑。打开帮助会保留辅助使用记录；未完整做对时可以修改再提交；完整完成后可重做当前题开启新轮次，第一次的证据不会被覆盖。
5. 从待复习页继续题型练习，或进行新题检查；学习记录展示逐次答案、辅助、重试和测评证据，不用刷题数量表示掌握。

格式错误不会计为有效作答。不定积分漏写 `+C` 记录为数学结果正确但书写不完整；补写后不会覆盖第一次记录。定积分最终应是常数，不带 `x` 或 `C`。不能可靠判断的写法显示“待核对”，不按错误处理。

每题每轮最多 10 次有效提交；重做当前题会开启新轮次。继续、切题、刷新不会重置轮次。报告区分未作答、需补练、辅助完成、重试完成、首次独立完整完成及待核对，显示名称以界面为准。

## 题库、预算与测评

首发 32 道作答题和 4 个完整示范。每个题型包含 1 道诊断、4 道普通训练、2 道即时复测、1 道次日检查。普通题单只公开 16 道训练题；保留题不参与搜索或自由选题。

当前所有题目均为临考原创通用训练，没有学校真题或课堂资料。资料结构可记录学校、学期、题号、页码和章节，默认依据顺序为近年真题、作业、PPT、教材；当前版本按教学先修关系和个人作答证据推荐，不虚构考试频次或预测得分。

推荐优先续练、处理最近的测评缺口及未独立完成的题型，并兼顾必要基础。学生始终可以自由选题。预算按题目预计用时、每题每轮一次扣减，预留涉及题型的复测与总结时间；不足以容纳完整安排时显示短练。它不读取实际学习速度，不是倒计时，也不保证在预算内学会全部内容。“调整”保留本次已用估时；下次学习可点“开始新一次练习”，按输入预算重新计算本次用时，保留所有题目轮次、草稿、作答与辅助证据。

- 起点诊断每题型一题，可在首次进入时整体完成，也可直接练习。
- 即时复测在该题型至少两道普通练习已有有效作答，或起点诊断已独立完整完成后开放。一次提供两道保留题。
- 首次完成该题型即时复测至少 24 小时后，次日检查开放。由服务时间计算，重启不会提前开放。
- 测评中只呈现当前题，禁止教学内容、AI、题单、导出及中途判定。提交或跳过后进入下一题，结束后统一查看结果。
- 可以明确提前结束本轮；已经呈现的题保持已见，当前未提交题不伪造作答。题池耗尽会说明原因，已见题不会重复充当新题复测。

## DeepSeek 自由答疑

不配置密钥时，全部普通学习功能及预设讲解可离线使用。要启用在线答疑，在本目录运行一次：

```powershell
Copy-Item .env.example .env
```

已有 `.env` 时直接编辑，避免覆盖。在本机编辑器填入 `DEEPSEEK_API_KEY`，保存后重启服务；无需把密钥贴进聊天或网页输入框。进程环境变量优先于 `.env`；源码、导出、浏览器状态与日志均不应含密钥。

| 配置项 | 默认值 | 含义 |
|---|---|---|
| `DEEPSEEK_API_KEY` | 空 | 空值关闭在线调用 |
| `DEEPSEEK_MODEL` | `deepseek-flash` | 官方 Chat Completions 模型名，可按账号可用模型调整 |
| `LINGKAO_AI_PARTICIPANT_LIMIT` | `30` | 每个匿名身份累计调用上限 |
| `LINGKAO_AI_DAILY_LIMIT` | `100` | 同一数据库的每日总上限，按 UTC 日切换 |
| `LINGKAO_AI_CONCURRENCY` | `2` | 同一数据库允许的同时在途请求数 |
| `LINGKAO_AI_TIMEOUT_SECONDS` | `45` | 应用等待期限，单位为秒 |

UTC 日在北京时间每日 08:00 切换。多份独立数据库的配额分别累计，并非 DeepSeek 账户级计费额度；清除一个学习者不会清除本机数据库每日累计数。

提问不超过 600 字，回复最多 1,000 tokens；非流式请求，关闭 thinking，不自动重试。发起时将当前题、审核解法、相关知识、当前题最近提交和最近六条对话发送给 DeepSeek；不发送其他题、完整题库或未见测评题。

等待期间可以继续编辑答案草稿，但提交、切题、测评等状态操作暂时锁定。可以取消等待；已发起的失败或取消请求仍占用次数，取消不保证远端停止处理。超时、取消或题目身份变化后的迟到回复不会应用。重启后的在途请求不会自动重发，到期限后解除等待。

只有成功保存 AI 回复才记录辅助使用；网络错误不改变独立证据。AI 回复按文本显示，不执行 HTML，也不能更改判题或训练安排。数学结果仍由现有确定性校验器核对。当前未配置有效密钥，真实 DeepSeek 问答未验收；模拟服务与错误分支覆盖见 [QA.md](QA.md)。

## 草稿和数据

默认数据库为 `data/lingkao-alpha.sqlite3`，用 `LINGKAO_DB_PATH` 可指定另一位置。数据库保存匿名身份、学习轮次、每次作答、辅助使用、题目暴露和 AI 请求状态。匿名身份通过 `lingkao_alpha_session` Cookie 恢复。

未提交答案仅在当前浏览器本地保存，不属于作答记录，也不包含在导出中。草稿按匿名身份、稳定题目标识、题目版本和练习轮次定位；切题、筛选、排序、刷新、基础补练返回时可恢复。重做一题不会清除其他题的草稿。AI 提问框也按当前题保存未发送输入。

跨标签页迟到的响应只清除它对应的已提交输入版本；进度冲突的输入在当前标签页保留副本，可复制，符合当前题条件时可恢复。关闭标签页会丢失此副本。浏览器禁止本地存储时会提示先复制，学习流程仍可继续；清理浏览器数据会删除草稿和身份凭证。

非测评阶段可导出已发生的学习记录；导出不含 Cookie、CSRF、密钥、尚未展示的参考答案或草稿。清除／下一位测试者会更换当前匿名身份并删除该身份的学习状态；需要保留资料时先导出并核对。

**同一浏览器配置的 Cookie 不按端口隔离。** 开发、不同批次和不同学生应使用独立浏览器配置，不能仅换端口；多个无痕窗口也可能共用身份。

## 从 v0.2 升级

1. 停止所有使用目标数据库的旧服务；备份数据库及仍存在的 SQLite 辅助文件，保留原浏览器配置。
2. 若继续个人练习，用原数据库启动新版即可。首次读取时自动将支持的 v0.2 状态迁移为状态版本 3，保留匿名身份、原始答案、判题版本和原判定，不重新判题。
3. 尚在 v0.2 诊断或复测中的会话继续使用 `legacy_engine.py` 与 `legacy_course.json` 的冻结内容；完成或主动结束后迁移。期间保持旧测评隔离。
4. 数学内容相同的旧练习映射到新版，保留帮助、暴露和已见记录。不能映射的历史作答以只读历史记录保留，不套用新版答案。
5. 能明确匹配的浏览器草稿迁入对应题目和轮次；无法匹配的旧输入提供复制入口，核对题目后再使用。

迁移写入后不要让旧服务继续修改同一库，也不要将新版数据库直接交回旧版。需要回到旧版时使用升级前备份与固定的旧版源码。测试使用临时旧状态样本，不对真实试用数据库做迁移测试。

**v0.3 首轮试用必须另开独立数据库。** 不用新版覆盖 `output/pilot-runs/batch-01/` 的 v0.2 资料；操作见 [新版试用指南](../pilot/README-v0.3.md)。原指南仍作为 v0.2 固定批次资料保留。

## 开发约定与边界

- Python 标准库服务，原生 HTML/CSS/JavaScript，SQLite，固定版本 SymPy；无需 Node.js 构建步骤。
- `GET /api/health` 返回版本、AI 是否已配置及本机运行标记；它不验证远端密钥有效性。
- `GET /api/catalog` 仅返回普通练习摘要；`GET /api/state` 返回当前页面所需信息。具体动作、并发及 AI 约定见 [CONTRACT.md](CONTRACT.md)。
- 服务端校验 CSRF、revision 与不透明题目实例；SQLite 以原始快照条件更新保护多个服务进程的并发。
- 数学预览只解析，不判题。原始表达式的定义域义务不会被化简消除；不定积分题库适用全实数范围，定积分题库只含有限连续区间。
- 本版没有账号收费、手写识别、推导过程评分、资料上传解析、排行榜、社区或在线部署；不承诺提分和掌握率。

验收结果集中维护在 [QA.md](QA.md)，版本变化见 [CHANGELOG.md](../CHANGELOG.md)。
