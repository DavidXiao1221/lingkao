# 临考 v0.2-alpha.1

这一版是可离线运行的换元积分训练验证版：诊断 → 示范 → 两道引导练习 → 两道独立变式 → 两道未见题复测 → 学习报告。另有一题可选基础补练。只核对最终表达式，不评价自由书写的推导过程。

## 启动与测试

需要 Python 3.10 或更新版本。Windows 双击 `start.bat`，启动后在浏览器打开 **http://127.0.0.1:8000**；保留终端窗口。第一次会在项目内创建 `.venv` 并安装固定版本的 SymPy，可能需要联网；之后依赖满足时不会执行安装，可以断网使用。不会改动全局 Python。

在本目录的 PowerShell 中也可以执行：

```powershell
.\start.bat
.\start.bat --port 8001
.\test.bat
```

macOS / Linux 可用 `bash start.sh`、`bash start.sh --port 8001`、`bash start.sh --test`。已准备好虚拟环境时，可直接运行 `.venv\Scripts\python.exe server.py --port 8000` 或 `.venv\Scripts\python.exe -m unittest discover -s tests -v`。

若端口被占用，换用 `--port 8001`，并打开终端显示的新地址。仅监听 `127.0.0.1`，本批没有在线部署或其他设备访问功能。

## 体验完整流程

1. 打开页面，选择学习时间并开始诊断。诊断和复测中只收集作答，不提供提示或中途对错。
2. 进入换元积分单元，阅读必要知识与示范，然后开始练习。可以查看分层提示、示范、完整讲解或三个预设答疑；使用记录会保留。
3. 用工具栏输入括号、分数、幂和函数，检查公式预览后提交。格式错误不消耗首次机会；不定积分漏写 `+C` 属于答案不完整，补写不会覆盖首次记录。
4. 完成两道引导和两道变式后，进入两道新题复测，结束后查看报告。复测仅开放一次；重复训练不会重新变为未见题。
5. 非测评阶段可导出学习记录。需要新一位测试者时，使用页面中的清除记录入口并确认；此操作删除当前浏览器对应的学习记录。

关闭页面、刷新或重启服务后，使用原浏览器、相同本机地址可继续学习。返回训练安排不会清空记录；重新进入会换发题目实例，旧页面的操作将被拒绝。基础补练完成后返回原位置。若看到页面已过期的提示，刷新获取当前状态后继续。

## 数据与边界

学习数据仅保存在 `data/lingkao-alpha.sqlite3`，使用独立的 `lingkao_alpha_session` Cookie，不读取参考原型的学习记录。不要在同一浏览器中同时给不同学生做测试；不同浏览器配置文件各自拥有独立匿名身份。数据库备份应在停止服务后进行，连同存在的 SQLite 辅助文件一并保管。

报告列出逐题证据，区分首次独立完整完成、辅助完成、错误后重试、跳过及待核对；不会把流程完成称为掌握，也不预测分数或通过率。提示、预设答疑、答案暴露和历次作答按课程版本保存。导出不含会话密钥及未展示的参考答案；诊断和复测期间服务端禁用导出。

**本批始终不调用在线 AI**，环境中即使有 API 密钥也不会启用。自由输入答疑暂不可用，三个预设讲解不依赖网络。其他积分单元、自由推导评分、延迟复测、账号、跨设备同步及在线部署均属于后续批次。

## 开发约定

- 服务与网页沿用 Python 标准库、原生 HTML/CSS/JavaScript；数学解析与判题使用固定版本 SymPy 的独立 UTF-8 子进程。
- 接口与状态约定见 `CONTRACT.md`。提交使用 `revision` 和不透明 `instance_id`，防止双击、旧页面或并发请求重复推进。
- `GET /api/health` 可检查版本及离线模式；静态文件仅允许首页、脚本和样式，源码和数据库不对浏览器公开。
- 测试启动独立的临时 SQLite 数据库，不修改真实学习记录。开发或测试可通过 `LINGKAO_DB_PATH` 指定数据库路径。
- 本目录包含当前开发版本；运行时不导入历史原型的学习记录。
- 本批自动化与浏览器验收记录见 [QA.md](QA.md)。
